# Forge plugin context

Generated by `forge-install`. Lists the plugins active in this repo and the agents that opt in to each. Read this file at session start before dispatching any agent that declares `plugins_optional`.

## Active plugins

### `agent-browser` (1.0.0)

Lightweight browser MCP for agent-driven web research. Wires Chrome DevTools MCP — lower token surface than full Playwright for read-only navigation, scraping, and screenshotting. Requires a Chrome/Chromium binary on the user's machine.

- **MCP namespace**: `mcp__chrome-devtools__*`
- **Tools supported**: claude-code, opencode, codex
- **Consumed by agents**: researcher
- **Install ownership**: user
- **User-installed binaries** (harness does not install):
    - `chrome` — https://www.google.com/chrome/  (or: apt install chromium)

### `context7` (1.0.0)

MCP server that retrieves authoritative library/API documentation by package + version. Used during exploration and proposal validation to ground specs in real docs.

- **MCP namespace**: `mcp__context7__*`
- **Tools supported**: claude-code, opencode, codex
- **Consumed by agents**: researcher, planner, validator, frontend, backend, database
- **Install ownership**: harness

### `engram` (1.0.0)

MCP-backed cross-session memory: project topic graphs, prompt capture, tiered observation policy. Used by planning + research agents to recall prior work.

- **MCP namespace**: `mcp__engram__*`
- **Tools supported**: claude-code, opencode, codex
- **Consumed by agents**: planner, researcher, synthesizer, agent-prep, agent-sync
- **Install ownership**: user
- **User-installed binaries** (harness does not install):
    - `engram` — claude plugin install engram

### `playwright-bridge` (1.0.0)

MCP bridge to Microsoft's official Playwright MCP server. Lets E2E and visual-test agents drive a browser via Playwright. Requires a one-time Playwright browser install on the user's machine.

- **MCP namespace**: `mcp__playwright__*`
- **Tools supported**: claude-code, opencode, codex
- **Consumed by agents**: tester-front, tester-back
- **Install ownership**: user
- **User-installed binaries** (harness does not install):
    - `playwright` — npx playwright install

### `rtk` (1.0.0)

CLI proxy that filters and compresses outputs of ls/cat/grep/find/git/test/lint/typecheck commands before they reach the model. 60-90% token reduction on covered commands. Ships an advisory PreToolUse Bash hook; for fully-automatic rewriting users should run `rtk init -g` themselves (rtk owns the protocol-correct rewrite surface).

- **MCP namespace**: `mcp__rtk__*`
- **Tools supported**: claude-code, opencode, codex
- **Consumed by agents**: frontend, backend, database, tester-front, tester-back, validator, researcher
- **Install ownership**: user
- **User-installed binaries** (harness does not install):
    - `rtk` — curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh
