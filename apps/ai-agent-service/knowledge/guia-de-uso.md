# Guia de uso

Para iniciar sesion, introduce tu correo y tu clave en la pantalla de acceso. Al autenticarte recibes un token de acceso de corta duracion y un token de renovacion. Cuando el token de acceso expira, la aplicacion lo renueva automaticamente mientras la sesion siga activa.

Para crear un usuario nuevo, un administrador abre la seccion de usuarios, pulsa el boton de crear, completa nombre, correo y rol, y confirma. Para cambiar el rol de un usuario existente, el administrador abre su ficha y elige otro rol. Para cerrar sesion, usa la opcion de salir en el menu superior; el token queda revocado.
